# Java Programming Projects

A comprehensive collection of Java programs covering core concepts from Object-Oriented Programming (OOP) to Data Structures, Algorithms, Multithreading, File I/O, and String Manipulation. This repository serves as a learning resource and reference guide for Java fundamentals.

## 1. Object-Oriented Programming (OOP)

### Abstraction & Inheritance

| File Name | Description |
|-----------|-------------|
| `Abstraction1.java` | Demonstrates abstract classes and methods. |
| `Abstraction2.java` | Another example of abstraction with interfaces or abstract classes. |
| `MultipleInheritance.java` | Shows how multiple inheritance is achieved in Java using interfaces. |

### Relationships (Has-A, Uses-A)

| File Name | Description |
|-----------|-------------|
| `Has_A_Relationship.java` | Demonstrates the "Has-A" relationship (composition/aggregation). |
| `Uses_A_Relationship.java` | Demonstrates the "Uses-A" relationship (dependency). |

### Inheritance Types

| File Name | Description |
|-----------|-------------|
| `Single_Inheritance.java` | Demonstrates single-level inheritance (one parent, one child). |
| `Multilevel_Inheritance.java` | Demonstrates multilevel inheritance (grandparent → parent → child). |
| `Hierarchical_Inheritance.java` | Demonstrates hierarchical inheritance (one parent, multiple children). |

### Method Overloading & Overriding

| File Name | Description |
|-----------|-------------|
| `MethodOverloading_1.java` | Overloading methods by changing the number of parameters. |
| `MethodOverloading_2.java` | Overloading methods by changing the data types of parameters. |
| `MethodOverriding.java` | Demonstrates runtime polymorphism via method overriding. |

### The `this` Keyword

| File Name | Description |
|-----------|-------------|
| `ThisClass_Variable.java` | Using `this` to refer to instance variables. |
| `ThisClass_Method.java` | Using `this` to call the current class's method. |
| `ThisClass_Constructor.java` | Using `this()` to call a constructor of the same class. |
| `ThisClass_Argument.java` | Passing `this` as an argument to a method. |

### The `super` Keyword

| File Name | Description |
|-----------|-------------|
| `SuperClass_Variable.java` | Accessing parent class variables using `super`. |
| `SuperClass_Method.java` | Calling parent class methods using `super`. |
| `SuperClass_Constructor.java` | Calling the parent class constructor using `super()`. |

### The `final` Keyword

| File Name | Description |
|-----------|-------------|
| `Final_Variable.java` | Demonstrates that a final variable cannot be reassigned. |
| `Final_Method.java` | Demonstrates that a final method cannot be overridden. |

### Static Keyword

| File Name | Description |
|-----------|-------------|
| `StaticKeyword_Variable1.java` | Demonstrates static variables (shared across all instances). |
| `StaticKeyword_Variable2.java` | Another example of static variables with counters. |
| `StaticKeyword_Method.java` | Demonstrates static methods (called without creating an instance). |
| `Static_Block.java` | Demonstrates static initialization blocks. |

## 2. Array Programs

### Basic Operations

| File Name | Description |
|-----------|-------------|
| `SumOfArray.java` | Calculates the sum of all elements in an array. |
| `LargestElements.java` | Finds the largest element in an array. |
| `Smallest.java` | Finds the smallest element in an array. |
| `SecondLargest.java` | Finds the second largest element in an array. |
| `EvenAndOdd.java` | Separates even and odd numbers from an array. |
| `CopyElements.java` | Copies elements from one array to another. |
| `SwapElements.java` | Swaps two elements in an array. |
| `Reverse.java` | Reverses the elements of an array. |
| `twoDarray.java` | Demonstrates 2D array operations. |
| `Insertion.java` | Inserts an element into an array at a given position. |
| `Deletion.java` | Deletes an element from an array. |
| `Updation.java` | Updates an element in an array. |

### Sorting Algorithms

| File Name | Description |
|-----------|-------------|
| `BubbleSort.java` | Implementation of the Bubble Sort algorithm. |

### Searching Algorithms

| File Name | Description |
|-----------|-------------|
| `Searching.java` | Demonstrates linear search (and possibly binary search). |

### Array Manipulation

| File Name | Description |
|-----------|-------------|
| `FindDuplicate.java` | Finds duplicate elements in an array. |
| `RemoveDuplicate.java` | Removes duplicate elements from an array. |
| `MissingValue.java` | Finds the missing number in a sequence (e.g., 1 to N). |
| `MoveZeroEnd.java` | Moves all zeros to the end of an array while maintaining order. |
| `TwoSumPair.java` | Finds a pair of elements that sum to a target value. |

### Prerequisites

- **Java Development Kit (JDK):** Version 8 or higher (Java 9+ for `module-info.java`).
- **IDE (Optional):** IntelliJ IDEA, Eclipse, or VS Code.
- **Terminal/Command Prompt.**
